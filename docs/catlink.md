# CatLink · 连连看玩法（当前实现）

> 本文记录当前代码的实际行为，作为后续调整玩法的基线。相关文件：`js/core/level.js`（关卡配置）、`js/core/grid.js`（棋盘与连通判定）、`js/core/game.js`（局内逻辑）、`js/scenes/play.js`（场景与结算）、`js/scenes/select.js`（选关页）、`js/ui/nav.js`（底部导航路由）、`js/core/save.js`（进度与奖励）、`js/core/shop.js`（道具名 / 价格 / `PROP_KEYS` 基线）、`js/render.js`（全局弹窗）、`js/scenes/shop.js`（商城购买）、`js/core/tasks.js`（每日任务）、`game.js`（场景注册 / 每日奖励入口）。
>
> 难度阶段与玩法规则以本文档为唯一基线，代码内不再重复维护玩法注释。

## 关卡生成

**没有静态关卡表，也没有服务端关卡数据**：每次开局由 `levelConfig(id)` 运行时生成配置，对任意关卡号都能返回配置，因此关卡数量无上限，只按关卡号划分 5 个难度阶段。配置带随机性，同一关重进时图案种类、特殊元素组合和落点都可能不同；存档只保存 `maxLevel`、`bestScore` 等进度标量，不保存关卡配置。

棋盘全局固定 `6×6`（36 格 / 18 对），不随关卡放大；从 48 种图案库中随机抽取 `kinds` 种组对后洗乱，生成时最多重排 50 次以避免开局死局。难度靠「图案种类 / 特殊元素 / 时间与步数限制」递进：

| 阶段 | 关卡 | 图案种类（随机） | 特殊元素 | 时间限制 | 步数限制 |
| --- | --- | --- | --- | --- | --- |
| 新手期 | 1–3 | 8–10 | 无 | 180 秒 | 不限 |
| 新手期 | 4–10 | 12–16 | 无 | 180 秒 | 不限 |
| 成长期 | 11–30 | 16–22 | 冰块 | 150 秒 | 不限 |
| 进阶期 | 31–45 | 20–26 | 冰块、锁链 | 不限时 | 24 步 |
| 进阶期 | 46–60 | 20–26 | 冰块、锁链、翻转 | 不限时 | 24 步 |
| 挑战期 | 61–100 | 24–32 | 冰块、锁链、翻转、移动 | 210 秒 | 25 步（双限） |
| 无尽期 | 101+ | 26–34 | 从 5 种里随机抽 2–5 种 | `max(120, 210 − ⌊(id−100)/5⌋×3)` 秒 | 不限 |

- 步数公式：`ceil(18×1.3)=24`（进阶期）、`ceil(18×1.35)=25`（挑战期）；`timeLimit`/`stepLimit` 为 `0` 表示不限。
- 阶段名：新手期 / 成长期 / 进阶期 / 挑战期 / 无尽期（英文 `Rookie/Growing/Advanced/Challenge/Endless`），分界为 10 / 30 / 60 / 100。
- 特殊元素密度：`ratio = min(0.3, 0.06 + id×0.002)`；冰块 `total×ratio×0.6`、锁链 `×0.4`、翻转 `×0.5`、移动 `×0.5`，炸弹 `total×bombChance×0.3`（`bombChance = 0.15`）。

## 基础规则

- 点击选中两个**相同图案**的方块，连线最多 **2 个拐点**（0/1/2 拐点均可）；棋盘外圈视为可通行，可绕到棋盘外侧连线；任何未消除的方块都会阻挡连线。
- 再次点击已选中方块可取消选中；配对失败有抖动/错误音反馈。
- 冰块方块第一次点击只破冰；翻转块未翻开时第一次点击只翻开（配对失败会重新盖回）；锁链块不可选中、不可匹配，相邻方块被消除时解锁。
- 移动块每 10 秒随机交换一次位置；炸弹块被消除时，在正常配对之外额外随机炸掉一对同图案方块（不连锁触发其它炸弹块）。
- 出现死局时自动洗牌（不消耗道具）；若因只剩锁链块导致无解，会先自动解开全部锁链。
- **清空棋盘即通关**，没有分数阈值要求；倒计时归零或步数耗尽即失败。

## 道具玩法

**背包与落盘**：4 种道具 `hint` / `shuffle` / `bomb` / `time`，数量存在账号级存档 `Save.data.props`，初始各 1，跨关卡、跨天持久，**不是每关赠送**；重玩已通关关卡照常消耗。`Game.start(levelId, items)` 直接接收这份存档对象并在其上扣减；`_spendItem()` 每次扣 1 并广播 `itemspent`，场景层监听后 `Save.set('props', game.items)` 即时落盘。局内购买完成后会把 `game.items` 重新指向存档的 `props`，避免引用失配导致道具无限使用；`_migrate` 按 `Shop.PROP_KEYS` 逐键补齐并钳制为非负整数。

**名称与价格**：显示名、价格、描述以 `js/core/shop.js` 的 `SHOP_ITEMS` 为唯一基线，`Shop.PROP_KEYS` 是 4 个 key 的唯一来源（存档迁移、每日奖励、开局背包规范化均复用它；局内购买用 `propItem()` 做白名单校验）。中文 提示 / 洗牌 / 炸弹 / 加时，英文 Hint / Shuffle / Bomb / +Time；价格 50 / 100 / 120 / 80。局内道具栏按 hint → shuffle → bomb → time 排列并显示数量角标；数量为 0 时角标变灰，但按钮仍可点击（提示「道具用完了」）。

| 道具 | 效果 | 失败 / 边界 |
| --- | --- | --- |
| 提示 `hint` | 高亮一对可消除方块 5 秒（`findAnyPair()`） | 无可消除对时不扣道具，提示「当前没有可提示的组合」 |
| 洗牌 `shuffle` | 重排剩余方块，`Grid.shuffle()` 会重排至有解（最多 60 次） | — |
| 炸弹 `bomb` | 进入选格模式，炸掉玩家指定一格 + 随机一个 `img` 相同的格，成对消除；每格 +5 分（通常共 +10 分），被炸格周围的锁链解锁 | 空格 / 道具耗尽分别提示；再次点炸弹取消选格；暂停或结算自动退出；选格期间点其它道具被拦截并提示 |
| 加时 `time` | 限时关（`timeLimit > 0`）倒计时 +30 秒 | 不限时关按钮真禁用；即使被绕过也会提示不可用 |

**炸弹成对规则**：道具炸弹炸掉玩家指定格，再随机找一个 `img` 相同的格一起炸；棋盘炸弹块则在正常配对之外额外随机炸掉一对同图案方块。牌堆由 `chosen.concat(chosen.slice())` 生成，每种图案数量恒为偶数，成对消除后不会出现「剩单张、无法配对」的残局；若起点格所属图案已无其它剩余格（异常残局），则只炸起点格（道具为玩家指定格，炸弹块为随机选中的格）。

**获取途径**：每日首次进入游戏随登录奖励发放 4 种道具各 1 个（见「计分与结算」）；商城「道具」分类、暂停弹窗「补充道具」→ 局内商店（列出 4 种）、失败弹窗「补充道具」按钮（回到局内商店）与两张快捷购买卡（提示 / 洗牌）均可用喵币补买。局内购买统一走 `Play._buyProp()`：白名单校验 → `Save.spendCoin(price)` → `props` +1 落盘 → 重新对齐 `game.items`；商城场景 `js/scenes/shop.js` 则直接按商品表扣币并给 `props` +1。喵币不足只提示、不扣数量，价格一律取商品表。

**交互细则**：提示高亮与选中由 `_boardChanged()` 在洗牌、移动换位、自动洗牌、消除与引爆后清除；「使用 N 次炸弹」任务只统计道具引爆（`fromItem`），棋盘炸弹块爆炸不计入，重玩旧关不计任务进度。

## 计分与结算

- 连击窗口 3 秒，单次得分 `round(10 × 1.2^(combo−1) × (1 + comboBonus))`；拥有孟加拉豹猫时 `comboBonus = 0.2`（连击分数 +20%）。分数只用于 `bestScore` 记录。
- **每日奖励**：按本地日期 `dailyGiftDay` 单次判重，`Save.claimDailyRewards()` 在「每日首次进入游戏」（启动或从后台恢复）一次性发放登录喵币 `100 + min(200, maxLevel×4)` 与 **4 种道具各 1 个**，立即写入存档并落盘。引擎层弹窗队列按「先每日登录奖励（喵币）、后每日赠礼（4 件道具 2×2 展示）」顺序弹出；道具在弹窗出现时已入账，点「收下」只关闭。弹窗期间暂停场景逻辑与计时、独占触摸输入，toast 仍正常推进；主页不再单独发币或弹 toast。
- 失败弹窗按真实失败原因显示（时间到 / 步数耗尽 / 还剩 N 对未消除），并提供「补充道具」入口（快捷购买卡与局内商店见「道具玩法」）。
- 星级：限时关按剩余时间比例 `>0.5 → 3 星`、`>0.2 → 2 星`、否则 1 星；限步关按 `剩余步数 > 步数上限×0.3 → 3 星`，否则 2 星。
- 过关喵币：`round((50 + min(150, id×5)) × (1 + 猫咪加成≤0.5))` + 连击奖励 `min(100, 最大连击×10)` + 剩余时间/步数奖励 `min(50, ...)`。**重玩已通关关卡（`id < maxLevel`）不发喵币、不推进 `maxLevel` 与猫种解锁、不计 `clear`/`combo`/`bomb`/`level` 任务进度**，结算奖励栏显示「重玩无奖励」；`bestScore` 仍可刷新。
- 进度：`maxLevel` 初始 1，通关后 `+1` 解锁下一关；`maxLevel` 达到 1/2/5/10/15/25/35/50/80/100 时解锁对应猫种。连续 3 关失败会触发猫咪骨折事件。
- 关卡切换：主页「开始游戏」/ 温馨版主页 / 底部导航 / 任务页均进入**选关页**（每页 24 关、`lv <= maxLevel` 才解锁且锁定关不可点、默认打开当前进度所在页、翻页按已解锁关数封顶）；选关页「继续闯关」直达当前 `maxLevel`，点关卡格进入指定关。胜利 / 失败 / 暂停弹窗都有「选关」按钮，胜利弹窗另可「下一关 / 领取奖励」，失败弹窗另可「重试 / 补充道具 / 回主页」。

## 偏差记录（已全部收口）

以下是整理当前玩法时发现的偏差记录，**不属于设计意图**；目前无遗留待优化项，玩法规则以本文档上文为基线。

已处理（道具专项收口）：每关赠送道具的死代码、存档/扣减边界（缺键导致负数）、加时按钮假禁用、炸弹选格模式无法取消与状态残留、提示静默失败及洗牌后高亮错位、局内商店不可达与价格三处硬编码、失败弹窗「还差 N 分」误导、英文界面背包仍显示中文、道具命名四处不一致、每日奖励两套判重互相覆盖、炸弹任务误计入棋盘炸弹块。

已处理（选关页接入）：`js/scenes/select.js` 注册为 `select` 场景，主页「开始游戏」/ 底部导航 / 任务页统一进入选关页，胜利 / 失败 / 暂停弹窗加「选关」按钮；同时修复返回键 `pop()` 无效、翻页无上限、6 行网格溢出压住翻页按钮、锁定关可被点进；重玩旧关不发喵币、不计任务进度。

已处理（难度注释收口）：删除 `js/core/level.js` 头部的难度阶段注释（原注释把 31–60 关统一写成「冰块 + 锁链 + 翻转」、61–100 写成「全元素」、无尽期写成「100+」，均与代码不符），阶段与特殊元素一律以本文档「关卡生成」表格为基线。实现不变：31–45 关只有冰块、锁链，`id > 45`（46 关起）才 `push('flip')`；61–100 关为冰块、锁链、翻转、移动四种；无尽期自 101 关起。

已处理（炸弹成对收口）：原 `3×3` 范围爆炸会随机炸掉奇数个方块，导致剩余图案不成对、可能无法通关；道具炸弹改为「指定一格 + 随机一个同图案方块」，棋盘炸弹块改为在正常配对之外额外随机炸掉一对同图案方块，两条路径都维持每种图案数量为偶数；同步更新商城描述、中英文选格提示与本文档规则，并补上被炸格周围的锁链解锁。
